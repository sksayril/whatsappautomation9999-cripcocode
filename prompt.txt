🧩 PROJECT REQUIREMENT

Build a WhatsApp Marketing Automation Desktop App using:

Electron.js (main, preload, renderer)

React (CDN version) inside HTML

whatsapp-web.js

SQLite database

CSV upload

Session-based WhatsApp auto-login

Message broadcasting

Random delay

Image/PDF document sending

Campaign dashboard

No Vite / No CRA / No bundler

Everything runs inside one HTML frontend file using React CDN.

🚀 APPLICATION FEATURES
1. Electron Architecture
Main Process

Creates BrowserWindow

Handles IPC events

Loads index.html

Preload

Exposes secure IPC methods using contextBridge

Renderer (Frontend)

Single HTML file

Uses React + ReactDOM CDN

Uses JSX by Babel

⚙️ 9. IPC Structure
Preload exposes APIs:
window.api = {
  sendMessage: (channel, data) => ipcRenderer.send(channel, data),
  receiveMessage: (channel, func) => ipcRenderer.on(channel, (event, ...args) => func(...args))
}


Events:

From frontend → backend

"upload-csv"

"get-templates"

"save-template"

"start-campaign"

"send-message"

"whatsapp-connect"

From backend → frontend

"log-update"

"qr-update"

"connection-status"

"campaign-progress"
